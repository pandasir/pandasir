# Hi, I'm panda

I build small, fast tools for the terminal — mostly in Rust.

- **[gander](https://github.com/pandasir/gander)** — a cross-platform interactive
  process viewer for Linux, macOS and FreeBSD. Keeps htop's keybindings and puts a
  live inspector beside the process table, so reading one process doesn't mean
  leaving the list.

  <img src="https://raw.githubusercontent.com/pandasir/gander/main/assets/demo.gif" width="720" alt="gander: the inspector follows the cursor down the list, t folds it into a tree, L switches to the full-width htop layout">

  ```bash
  brew install pandasir/tap/gander
  ```

- **[webpilot](https://github.com/pandasir/webpilot)** — a local Web UI acceptance and
  regression plugin for Codex: acceptance runs against a real browser, rerunnable
  test cases, Playwright export, and a test center.
